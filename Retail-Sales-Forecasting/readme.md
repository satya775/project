## 📌 Project Overview

Retail businesses need accurate sales forecasting to optimize inventory, improve demand planning, and maximize revenue. This project leverages historical Rossmann Store Sales data to build predictive models that forecast future sales using Machine Learning and Time Series techniques.

---

## 🎯 Problem Statement

Retail stores often face challenges in predicting future sales due to promotions, holidays, customer behavior, seasonality, and competition. This project aims to build an accurate forecasting model that helps businesses make data-driven decisions.

---

## 📂 Dataset

- **Dataset:** Rossmann Store Sales
- **Source:** Kaggle
- Historical daily sales records of Rossmann stores.
